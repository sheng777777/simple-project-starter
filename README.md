# 🚀 Simple Project Starter

A minimal and clean starter template to kick off any project without wasting time on setup.

---

## ✨ Features

* Clean folder structure
* Environment variable setup
* Basic test example
* Ready-to-use `.gitignore`

---

## 📦 Getting Started

```bash
git clone https://github.com/sheng777777/simple-project-starter
cd simple-project-starter
npm install
npm start
```

---

## 📁 Project Structure

* `src/` → main code
* `tests/` → test files
* `docs/` → documentation

---

## 🔐 Environment Variables

Copy `.env.example` to `.env` and update values.

---

## 🧪 Run Tests

```bash
npm test
```
